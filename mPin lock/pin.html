Escalation tiers

Cooldown length grows with each wrong attempt — the counter never resets just because a cooldown expires, only a correct PIN clears it.

Attempt Result Cooldown
1–3 Warning shown, no lock —
4 Locked 1 minute
5 Locked 5 minutes
6 Locked + admin notified 30 minutes
7+ Locked + admin notified 24 hours
Demo uses 10s / 20s / 40s / 90s in place of the real 1m / 5m / 30m / 24h, so the escalation is visible without waiting.
